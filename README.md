# CutoffIQ - Anna University College Explorer

![CutoffIQ Logo](public/logo.svg)

## Overview

CutoffIQ is a comprehensive web application designed to help engineering aspirants explore and compare Anna University affiliated colleges based on counseling cutoff data. This tool streamlines the college selection process by providing interactive visualizations, trend analysis, and detailed comparisons of cutoff marks across multiple years.

## Features

### College Finder 🔍
- Filter colleges by cutoff marks, categories (OC, BC, MBC, SC), courses, districts, and college types
- Sort results by various criteria including cutoff marks and trends
- Bookmark colleges for later reference
- Real-time filtering with responsive design

### Trend Analysis 📈
- Interactive data visualizations showing 3-year cutoff trends (2022-2024)
- Statistical insights including average cutoffs and percentage changes
- Color-coded indicators for rising, stable, or falling trends
- Comparative year-by-year analysis

### College Comparison ⚖️
- Side-by-side comparison of up to 4 colleges at once
- Automatic detection of common courses between selected institutions
- Detailed view of cutoff marks across multiple years
- Export comparison data for offline analysis

### Bookmarking System 🔖
- Save favorite colleges for future reference
- Reorder bookmarked colleges by priority
- Export bookmarked colleges to CSV format
- Quick-access to detailed information about saved colleges

## Technologies Used

- **Frontend**: React, TypeScript, Tailwind CSS
- **UI Components**: Shadcn UI component library
- **State Management**: React Context API, Custom Hooks
- **Routing**: React Router
- **Data Visualization**: Custom chart components
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/dhivagar1209/cutoffiq.git
cd cutoffiq
```

2. Install dependencies
```bash
npm install
# or
yarn
```

3. Start the development server
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to `http://localhost:3000`

## Usage

### Finding Colleges
1. Navigate to the "Find Colleges" section
2. Enter your expected cutoff marks
3. Select your category, preferred courses, and districts
4. View matching colleges and sort as needed
5. Bookmark interesting colleges for later comparison

### Comparing Colleges
1. Navigate to the "Compare" section
2. Search and select up to 4 colleges to compare
3. Choose a specific course and category
4. View side-by-side comparison of cutoff data
5. Analyze 3-year trends for each college

### Analyzing Trends
1. Go to the "Trends" section
2. Select colleges you want to analyze
3. Choose a course and category
4. View detailed visualizations of cutoff trends
5. Check statistical summaries for quick insights
